# Séance 9 - Atelier de synthèse : réaliser une production cartographique complète

**Thème :** mobiliser l'ensemble des acquis du semestre

> 🚧 **Séance en cours de préparation.** Le plan ci-dessous est indicatif ; le support détaillé, l'énoncé du TD et le corrigé seront ajoutés prochainement.

## Objectif

Mobiliser **l'ensemble des acquis du semestre**. À partir de données et de documents fournis par l'enseignant, suivre toute la démarche :

**données → identification de l'information → choix de l'implantation → choix des variables visuelles → figurés → légende → carte / croquis → vérification critique**

- d'un atelier de préparation à l'évaluation ;
- d'une production notée ;
