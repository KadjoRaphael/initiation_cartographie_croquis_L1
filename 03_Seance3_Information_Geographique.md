# Séance 3 - L'information géographique : QUOI ? OÙ ? COMMENT ?

**Thème :** identifier l'information que l'on veut représenter avant de choisir un figuré

> 🚧 **Séance en cours de préparation.** Le plan ci-dessous est indicatif ; le support détaillé, l'énoncé du TD et le corrigé seront ajoutés prochainement.

## Objectif

Apprendre à **identifier l'information que l'on veut représenter avant de choisir un figuré**. Cette séance regroupe les composantes du signe graphique.

## Contenu

- Qu'est-ce qu'une information géographique ?
- Les trois questions fondamentales :
  - **QUOI ?** → quel phénomène ?
  - **OÙ ?** → où est-il localisé ?
  - **COMMENT ?** → comment le représenter ?
- Les trois implantations : **ponctuelle**, **linéaire**, **surfacique**
- Information **qualitative** / **quantitative**
- Valeurs **absolues** et valeurs **relatives** (de manière très introductive)

**Exemple :** une ville → point ; une route → ligne ; une forêt → surface.

## TD / Activité pratique

À partir de plusieurs informations fournies, **déterminer leur implantation et le type d'information** (qualitative ou quantitative).
